# PowerBI_PROJECT
Power BI project analyzing the ElectroHub dataset with data transformation, star schema modeling, and interactive dashboards to uncover insights on sales, profit, discounts, and customer trends. 

## 📌 Overview
This project demonstrates end‑to‑end **data transformation, modeling, and visualization** using Power BI on the ElectroHub dataset.

## 🔧 Data Transformation
- Handled null values in price per unit and total sales.
- Created calculated fields (discount %, discount values, net sales).
- Applied star schema with primary/foreign keys and cardinality.

## 📊 Data Modeling & Reporting
- Established relationships between fact and dimension tables.
- Built interactive dashboards with filters and slicers.
- Answered business questions:
  - Top/Bottom 5 products by sales, profit, and quantity.
  - Sales trends (daily, monthly, quarterly, annually).
  - Relationship between sales & profit.
  - City‑wise sales distribution.
  - Total number of orders.
  - Comparative analysis between selected time periods.
  - Order‑level details with filters (Product, Date, Customer ID, Promotion Categories).
